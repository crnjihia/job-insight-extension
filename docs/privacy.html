Privacy Policy

Effective Date: October 3, 2026

Job Insight Extension is a developer and candidate companion Chrome extension that assists job seekers by overlaying critical application intelligence (salary benchmarks, company ratings, and AI-generated match scores) directly onto job-listing portals including LinkedIn, BrighterMonday, and Fuzu.

1️⃣ What Data Is Processed?

  • CV Text: When you upload a CV (PDF) through the extension options or popup panel, the raw text is extracted client-side and securely communicated to the backend API (/cv/upload) solely for computing the resume-to-job match score.
  • Job Listing Details: Job title, employer name, and full description are extracted from supported target sites in-memory only and transmitted to the /analyze endpoint.
  • Usage Preferences: Stored locally in chrome.storage.sync and chrome.storage.local (salary currency preference, notification toggles, cached CV snippet). No personally identifiable data is stored beyond what you explicitly upload.

2️⃣ How Data Is Utilized & Cached

  • Zero Permanent Retention: CV text and job descriptions are transformed into a SHA-256 cryptographic hash. The resulting hash is cached in Redis for 24 hours to prevent redundant compute calls. The raw CV payload is discarded from memory once the response completes.
  • Dual Scoring Pipeline: When running in default heuristic mode, scoring occurs locally with zero third-party transmissions. When configured with an Anthropic Claude API key, the in-memory payload is evaluated by Anthropic solely for the duration of the inference request.
  • Public Intelligence Data: Company Glassdoor ratings and regional salary benchmarks are cached in MongoDB; these datasets are publicly sourced.

3️⃣ Third-Party Visibility & Data Sharing

  • Candidate Sole Ownership: We do not sell, license, rent, or monetize your resume, search behavior, or application data.
  • Anthropic (Claude API): If the optional Claude 3.5 Sonnet engine is enabled by the backend administrator, the in-memory payload is sent to Anthropic's secure inference API under their commercial data privacy terms (zero customer training).
  • Security Logs: Server logs (IP address, timestamps) are maintained strictly for rate limiting (20 req/min per IP) and DDoS defense for a maximum of 30 days.

4️⃣ Security Measures

  • All API traffic is enforced over TLS / HTTPS.
  • Origin-validated CORS and API-key middleware protect internal endpoints.
  • Secrets and API credentials remain isolated in server-side environment variables and are never bundled into the client extension.

5️⃣ Candidate Rights & Deletion

  • You can delete your stored CV at any time via the extension Options tab. This immediately purges the cached CV text from local Chrome storage.
  • You can disable or uninstall the extension with one click via chrome://extensions/.
