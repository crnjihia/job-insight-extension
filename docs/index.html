Why Job Insight

Engineered to Supercharge Your Tech Career

Stop applying blindly into black holes. Job Insight equips you with instant data-driven insights right where you browse.

🎯

AI Match Score & Gap Analysis

Evaluates your uploaded CV against job descriptions to compute a reliable 0–100% score. Categorizes missing requirements into actionable priority tiers (P1/P2/P3) so you can tailor your application in seconds.

💰

Regional Salary Benchmarking

Eliminates salary ambiguity with localized compensation bands (minimum, median, maximum). Specially calibrated for East Africa (KES in Nairobi) and international tech centers (USD/EUR).

🏢

Glassdoor Employer Ratings

Surface company reputation, aggregate review volume, and sentiment score without ever leaving the job board. Filter toxic workplaces before wasting your time in multi-stage interviews.

🛡️

Encapsulated Shadow DOM

The overlay drawer is injected into an isolated Shadow Root with React 18, ensuring zero stylesheet collisions, zero layout disruptions, and perfectly smooth animations regardless of host site CSS.

⚡

Dual Intelligence Engine

Runs out-of-the-box with a free, instant heuristic keyword and seniority weight matching engine. Seamlessly connects to Claude 3.5 Sonnet for deep semantic qualifications reasoning when configured.

🔒

100% Privacy & Local-First

Client-side PDF extraction with local encrypted storage in chrome.storage.local. SHA-256 caching ensures your resume is processed in-memory and never permanently stored on external servers.

  • Instant badge attachment alongside job title header
  • Full job description parser excluding promotional ads
  • Floating sparkle trigger for quick drawer expansion

Installation & Setup

Get Up and Running in 3 Minutes

Follow these quick steps to install the extension in Google Chrome or fire up the local development stack.

1

Download or Clone the Repository

Clone the repository via Git or download the pre-packaged v0.1.0 release archive:

git clone https://github.com/crnjihia/job-insight-extension.git
2

Install & Build the Extension

Install dependencies and generate the production extension/dist bundle:

npm install && npm run build:extension
3

Load Unpacked in Chrome

Open chrome://extensions/ in your browser, toggle on Developer mode (top-right), click Load unpacked, and select the extension/dist folder. Pin Job Insight to your toolbar!

1

Configure Environment Variables

Copy the example file to create backend/.env (offline heuristic works without API keys):

cp backend/.env.example backend/.env
2

Build and Start the Express API

Compile TypeScript and launch the API server on port 4000:

npm --prefix backend run build && npm --prefix backend start
3

Verify Backend Health

Inspect API status at http://localhost:4000/health.

1

Start Full Stack with Docker Compose

Spins up Node.js API, MongoDB, and Redis in isolated containers with persistent volumes:

docker-compose up -d --build
2

Run Automated Test Suites

Execute Vitest unit & integration tests across the monorepo:

npm test
Frequently Asked Questions

Everything You Need to Know

Yes! The default Intelligent Heuristic Engine runs 100% free with zero configuration and zero external API keys needed. You can optionally plug in your Anthropic Claude API key for enhanced deep reasoning if desired.
Your privacy is our highest priority. Uploaded CVs are extracted and stored locally in your browser's encrypted chrome.storage.local. When sent to the scoring endpoint, descriptions and CV text are processed in-memory and deduplicated using SHA-256 hashes. No resume files are ever permanently stored on third-party servers.
Job Insight is built on Chrome Manifest V3 and supports Google Chrome, Brave, Arc, Microsoft Edge, and any Chromium browser. Out of the box, it supports LinkedIn Jobs, BrighterMonday (Kenya, Uganda, Nigeria), and Fuzu Africa.
Salary estimates are derived from verified regional market data. For Kenyan listings, figures are displayed in monthly Kenyan Shillings (KES), adjusted for seniority tier (Senior, Mid, Junior). For international and remote postings, figures are benchmarked in annual USD/EUR.
